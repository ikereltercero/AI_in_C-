Amplio conocimiento de Linux embebido.

Conocimiento avanzado de redes y protocolos de comunicaciones.

Experiencia en sistemas concurrentes y multihilo.

Experiencia en diseño de sistemas distribuidos o desacoplados.

Capacidad para traducir necesidades funcionales en soluciones técnicas.



Se valorará especialmente:

Experiencia con frameworks C++ modernos (Boost, POCO, Drogon…).

Conocimiento en sistemas de mensajería (ZeroMQ, RabbitMQ…).

Experiencia en arquitecturas orientadas a eventos.

Experiencia en Yocto, Buildroot y optimización de sistemas embebidos.

Experiencia influyendo en decisiones técnicas a nivel de producto o plataforma.

Job Description Summary



We are looking for a passionate Embedded Software Development Engineer who enjoys building reliable, high-quality software that powers critical industrial products. If you thrive working close to hardware, love solving complex system challenges and want to contribute to technology that supports the energy transition, we’d love to hear from you — apply and let’s connect.



In this role, you will design, develop and maintain embedded software based on Linux and C/C++, working with modern development environments, virtualization and DevSecOps practices. You will collaborate with global teams to deliver robust, secure and high-performance solutions used in demanding industrial environments.



Job Description



Essential Responsibilities:



Architects, designs, and leads the development of critical components or entire embedded software product. Provides strong expertise in areas including, but not limited to, networks, operating systems, cybersecurity, databases, applications, virtualization.

Drives high-level technical discussions; leads architectural design sessions and translates complex technical requirements into actionable solutions through whiteboarding.

Collaborates closely with cross-functional teams to execute in a fast-paced delivery environment, ensuring high-quality output that meets critical product release goals.

Maintains high code quality standards through the implementation of best practices, performing expert-level code reviews, and designing comprehensive unit testing frameworks.



Required Qualifications



Bachelor’s Degree in Computer Science, Electrical Engineering, or Computer Engineering.

Proven, extensive experience in the full-cycle development of embedded systems.



Desired Characteristics



Deep experience with (embedded) Linux and RTOS (task management, context switching, interrupt handling, etc).

Expert proficiency in C/C++ for embedded systems.

Strong experience architecting solutions using Microservices, Container technologies (Docker, Kubernetes), Virtualization (Hypervisor types, VM management, network configuration).

Strong experience designing and maintaining robust CI/CD pipelines, DevSecOps workflows, and automated test frameworks.

Hands-on experience with advanced toolchains, software analyzers, and debugging across embedded and virtualized targets.

Proven experience integrating protocols such as IEC 61850 (GOOSE, MMS, SV), DNP3, Modbus, IEC 60870-5-104, IEEE C37.118, IEEE 1588, PRP/HSR.

Familiar with compliance to cybersecurity standards applicable to electrical systems including IEC 60255, NERC CIP, IEC 62443, IEC 62351

// Nivel 1: Fuerza Bruta
void matmul_naive(const std::vector<float>& A, const std::vector<float>& B, std::vector<float>& C, int N) {
    std::fill(C.begin(), C.end(), 0.0f);
    for (int i = 0; i < N; ++i) {
        for (int j = 0; j < N; ++j) {
            float sum = 0.0f;
            for (int k = 0; k < N; ++k) {
                sum += A[i * N + k] * B[k * N + j];
            }
            C[i * N + j] = sum;
        }
    }
}

// Nivel 2: Cache Tiling (Bloqueo L1)
void matmul_tiled(const std::vector<float>& A, const std::vector<float>& B, std::vector<float>& C, int N, int BLOCK_SIZE) {
    std::fill(C.begin(), C.end(), 0.0f);
    for (int i = 0; i < N; i += BLOCK_SIZE) {
        for (int j = 0; j < N; j += BLOCK_SIZE) {
            for (int k = 0; k < N; k += BLOCK_SIZE) {

                for (int ii = i; ii < std::min(i + BLOCK_SIZE, N); ++ii) {
                    for (int jj = j; jj < std::min(j + BLOCK_SIZE, N); ++jj) {
                        float sum = 0.0f;
                        for (int kk = k; kk < std::min(k + BLOCK_SIZE, N); ++kk) {
                            sum += A[ii * N + kk] * B[kk * N + jj];
                       }
                        C[ii * N + jj] += sum;
                    }
                }
            }
        }
    }
}

// Nivel 3: Cache Tiling + SIMD AVX2
void matmul_tiled_simd(const std::vector<float>& A, const std::vector<float>& B, std::vector<float>& C, int N, int BLOCK_SIZE) {
    std::fill(C.begin(), C.end(), 0.0f);
    for (int i = 0; i < N; i += BLOCK_SIZE) {
        for (int j = 0; j < N; j += BLOCK_SIZE) {
            for (int k = 0; k < N; k += BLOCK_SIZE) {
                
                for (int ii = i; ii < std::min(i + BLOCK_SIZE, N); ++ii) {
                    for (int kk = k; kk < std::min(k + BLOCK_SIZE, N); ++kk) {
                        __m256 a_val = _mm256_set1_ps(A[ii * N + kk]);
                        for (int jj = j; jj < std::min(j + BLOCK_SIZE, N); jj += 8) {
                            __m256 b_val = _mm256_loadu_ps(&B[kk * N + jj]);
                            __m256 c_val = _mm256_loadu_ps(&C[ii * N + jj]);
                            c_val = _mm256_fmadd_ps(a_val, b_val, c_val);
                            _mm256_storeu_ps(&C[ii * N + jj], c_val);
                        }
                    }
                }
            }
        }
    }
}

// Nivel 4: Cache Tiling + SIMD AVX2 + Multithreading (El Dios del Rendimiento)
void matmul_tiled_simd_omp(const std::vector<float>& A, const std::vector<float>& B, std::vector<float>& C, int N, int BLOCK_SIZE) {
    std::fill(C.begin(), C.end(), 0.0f);
    
    // Repartimos los bloques de filas entre todos los núcleos de tu CPU
    #pragma omp parallel for
    for (int i = 0; i < N; i += BLOCK_SIZE) {
        for (int j = 0; j < N; j += BLOCK_SIZE) {
            for (int k = 0; k < N; k += BLOCK_SIZE) {
                for (int ii = i; ii < i + BLOCK_SIZE; ++ii) {
                    for (int kk = k; kk < k + BLOCK_SIZE; ++kk) {
                        __m256 a_val = _mm256_set1_ps(A[ii * N + kk]);
                        for (int jj = j; jj < j + BLOCK_SIZE; jj += 8) {
                            __m256 b_val = _mm256_loadu_ps(&B[kk * N + jj]);
                            __m256 c_val = _mm256_loadu_ps(&C[ii * N + jj]);
                            c_val = _mm256_fmadd_ps(a_val, b_val, c_val);
                            _mm256_storeu_ps(&C[ii * N + jj], c_val);
                        }
                    }
                }
            }
        }
    }
}

class HttpParser {
public:
    static HttpRequest parse(const std::string& raw_request) {
        HttpRequest req;
        if (raw_request.empty()) return req;

        std::istringstream stream(raw_request);
        std::string request_line;
        std::getline(stream, request_line);

        // 1. Parsear la Request Line (Ej: GET /predict?f1=5 HTTP/1.1)
        size_t method_end = request_line.find(' ');
        if (method_end != std::string::npos) {
            req.method = request_line.substr(0, method_end);
            
            size_t path_end = request_line.find(' ', method_end + 1);
            if (path_end != std::string::npos) {
                std::string full_path = request_line.substr(method_end + 1, path_end - method_end - 1);
                req.version = request_line.substr(path_end + 1);
                
                // Limpiar retorno de carro (\r) de Windows
                if (!req.version.empty() && req.version.back() == '\r') {
                    req.version.pop_back();
                }

                // Separar la ruta pura de los parámetros
                size_t query_pos = full_path.find('?');
                if (query_pos != std::string::npos) {
                    req.path = full_path.substr(0, query_pos);
                    req.query = full_path.substr(query_pos + 1);
                } else {
                    req.path = full_path;
                }
            }
        }

        // 2. Parsear los Headers (Ej: "Host: localhost:8080")
        std::string header_line;
        while (std::getline(stream, header_line) && header_line != "\r") {
            size_t colon = header_line.find(':');
            if (colon != std::string::npos) {
                std::string key = header_line.substr(0, colon);
                std::string value = header_line.substr(colon + 2); // Saltar ": "
                
                if (!value.empty() && value.back() == '\r') {
                    value.pop_back();
                }
                req.headers[key] = value;
            }
        }

        // 3. Parsear el Body (Para Fase 10 - POST requests)
        std::stringstream body_stream;
        body_stream << stream.rdbuf();
        req.body = body_stream.str();

        return req;
    }
};

// ==============================================================================
// C++20 CONCEPT: Valida que una función sea un Handler HTTP válido en tiempo de compilación.
// Exige que la función acepte (const HttpRequest&, HttpResponse&) y retorne void.
// ==============================================================================
template<typename F>
concept HttpHandlerFunction = requires(F handler, const HttpRequest& req, HttpResponse& res) {
    { handler(req, res) } -> std::same_as<void>;
};

class Router {
private:
    // Estructura clave-valor para asociar "METODO + RUTA" (ej: "GET /predict") a una función lambda o puntero
    std::unordered_map<std::string, std::function<void(const HttpRequest&, HttpResponse&)>> routes;

    std::string make_key(const std::string& method, const std::string& path) const {
        return method + " " + path;
    }

public:
    Router() = default;

    // Método genérico con C++20 Concepts para registrar rutas de forma segura
    template<HttpHandlerFunction F>
    void add_route(const std::string& method, const std::string& path, F&& handler) {
        std::string key = make_key(method, path);
        routes[key] = std::forward<F>(handler);
    }

    // El núcleo del enrutador: busca si la ruta existe y ejecuta su lógica o devuelve un 404
    void route(const HttpRequest& req, HttpResponse& res) const {
        std::string key = make_key(req.method, req.path);
        
        auto it = routes.find(key);
        if (it != routes.end()) {
            // Si la ruta está registrada, ejecutamos su función asociada (Controlador)
            it->second(req, res);
        } else {
            // Si no existe, devolvemos HTTP 404 estandarizado
            res.status_code = 404;
            res.status_message = "Not Found";
            res.headers["Content-Type"] = "text/plain; charset=utf-8";
            res.body = "ERROR 404: La ruta '" + req.path + "' no existe en este servidor.\n";
        }
    }
};

// 1. Definimos el Concept: Toda función de Loss debe tener un forward y un backward con esta firma exacta.
template<typename T>
concept LossFunction = requires(T, const Tensor& pred, const float* target, size_t num_outputs) {
    { T::forward(pred, target, num_outputs) } -> std::convertible_to<float>;
    { T::backward(pred, target, num_outputs) } -> std::same_as<Tensor>;
};

// ==========================================
// MEAN SQUARED ERROR (Para regresión o XOR)
// ==========================================
struct MSE {
    static float forward(const Tensor& pred, const float* Y_batch, size_t num_outputs) {
        float total_loss = 0.0f;
        for (size_t i = 0; i < pred.rows; ++i) {
            for (size_t j = 0; j < pred.cols; ++j) {
                float diff = pred.at(i, j) - Y_batch[i * num_outputs + j];
                total_loss += diff * diff;
            }
        }
        return total_loss / pred.rows;
    }

    static Tensor backward(const Tensor& pred, const float* Y_batch, size_t num_outputs) {
        Tensor dLoss(pred.rows, pred.cols);
        for (size_t i = 0; i < pred.rows; ++i) {
            for (size_t j = 0; j < pred.cols; ++j) {
                float diff = pred.at(i, j) - Y_batch[i * num_outputs + j];
                dLoss.at(i, j) = (2.0f * diff) / pred.rows;
            }
        }
        return dLoss;
    }
};

// CROSS-ENTROPY + SOFTMAX (Para clasificación multiclase como Iris)
// ==========================================
struct CrossEntropy {
    static float forward(const Tensor& pred, const float* Y_batch, size_t num_outputs) {
        float total_loss = 0.0f;
        
        for (size_t i = 0; i < pred.rows; ++i) {
            // Truco de estabilidad numérica: restar el máximo antes del exp()
            float max_val = pred.at(i, 0);
            for (size_t j = 1; j < pred.cols; ++j) {
                max_val = std::max(max_val, pred.at(i, j));
            }

            float sum_exp = 0.0f;
            for (size_t j = 0; j < pred.cols; ++j) {
                sum_exp += std::exp(pred.at(i, j) - max_val);
            }

            for (size_t j = 0; j < pred.cols; ++j) {
                if (Y_batch[i * num_outputs + j] == 1.0f) { // Solo nos importa la clase real (One-Hot)
                    float softmax_prob = std::exp(pred.at(i, j) - max_val) / sum_exp;
                    // Evitar log(0) sumando un epsilon
                    total_loss += -std::log(softmax_prob + 1e-8f);
                }
            }
        }
        return total_loss / pred.rows;
    }

    static Tensor backward(const Tensor& pred, const float* Y_batch, size_t num_outputs) {
        Tensor dLoss(pred.rows, pred.cols);
        
        for (size_t i = 0; i < pred.rows; ++i) {
            float max_val = pred.at(i, 0);
            for (size_t j = 1; j < pred.cols; ++j) {
                max_val = std::max(max_val, pred.at(i, j));
            }

            float sum_exp = 0.0f;
            for (size_t j = 0; j < pred.cols; ++j) {
                sum_exp += std::exp(pred.at(i, j) - max_val);
            }

            // Derivada mágica y simplificada de Softmax + CrossEntropy: (Probabilidad - ValorReal) / BatchSize
            for (size_t j = 0; j < pred.cols; ++j) {
                float softmax_prob = std::exp(pred.at(i, j) - max_val) / sum_exp;
                float y_true = Y_batch[i * num_outputs + j];
                dLoss.at(i, j) = (softmax_prob - y_true) / pred.rows;
            }
        }
        return dLoss;
    }
};

    if (!in) throw std::runtime_error("Error leyendo dato POD.");
}

// 3. Escritura/Lectura de vectores dinámicos
template<POD T>
void writeBinary(std::ofstream& out, const std::vector<T>& vec) {
    size_t sz = vec.size();
    writeBinary(out, sz); 
    out.write(reinterpret_cast<const char*>(vec.data()), sz * sizeof(T));
    if (!out) throw std::runtime_error("Error escribiendo vector.");
}

template<POD T>
void readBinary(std::ifstream& in, std::vector<T>& vec) {
    size_t sz;
    readBinary(in, sz); 
    vec.resize(sz);     
    in.read(reinterpret_cast<char*>(vec.data()), sz * sizeof(T));
    if (!in) throw std::runtime_error("Error leyendo vector.");
}

class Tensor {
public:
    std::vector<float> data;
    std::vector<float> grad; 
    size_t rows;
    size_t cols;

    Tensor() : rows(0), cols(0) {}
    Tensor(size_t r, size_t c) : rows(r), cols(c), data(r * c, 0.0f), grad(r * c, 0.0f) {}

    float& at(size_t r, size_t c) {
        return data[r * cols + c];
    }
    const float& at(size_t r, size_t c) const {
        return data[r * cols + c];
    }

    size_t size() const { return rows * cols; }
    void zero_grad() { std::fill(grad.begin(), grad.end(), 0.0f); }
};

class ThreadPool {
private:
    std::vector<std::thread> workers;
    std::queue<std::function<void()>> tasks; // La cola de trabajos (clientes)
    
    std::mutex queue_mutex; // Candado para evitar que dos hilos saquen al mismo cliente
    std::condition_variable condition; // Señal para "despertar" a los hilos dormidos
    volatile bool stop; // Bandera para el Graceful Shutdown
    
    size_t max_queue_size;
public:
    ThreadPool(size_t num_threads = std::thread::hardware_concurrency(), size_t max_queue = 1000) : stop(false), max_queue_size(max_queue) {
        // Creamos los hilos trabajadores de antemano
        for(size_t i = 0; i < num_threads; ++i) {
            workers.emplace_back([this] {
                while(true) {
                    std::function<void()> task;
                    {
                        // 1. El hilo coge el candado
                        std::unique_lock<std::mutex> lock(this->queue_mutex);
                        
                        // 2. Se duerme si no hay tareas y no hemos ordenado parar
                        this->condition.wait(lock, [this] { 
                            return this->stop || !this->tasks.empty(); 
                        });
                        
                        if(this->stop && this->tasks.empty()) return; // Fin del trabajo
                        
                        // 3. Saca la tarea de la cola
                        task = std::move(this->tasks.front());
                        this->tasks.pop();
                    } // 4. Suelta el candado automáticamente aquí
                    
                    // 5. Ejecuta la tarea (La inferencia HTTP) SIN bloquear a los demás
                    task();
                }
            });
        }
        std::cout << "[INFO] ThreadPool iniciado con " << num_threads << " workers.\n";
    }

    // Método para meter clientes en la cola (Usaremos lambdas de C++20)
    template<class F>
    bool enqueue(F&& f) {
        {
            std::lock_guard<std::mutex> lock(queue_mutex);
            // Pool detenido: no aceptamos nuevas tareas.
            if (stop) {
            throw std::runtime_error("enqueue on stopped ThreadPool");
        }
        // Aquí limitamos de verdad la cola. Si hay más tareas de las permitidas, rechazamos.
        if (tasks.size() >= max_queue_size) {
            return false; 
        }
            tasks.emplace(std::forward<F>(f));
        }
        condition.notify_one(); // Despierta a 1 hilo dormido
        return true;
    }

    ~ThreadPool() {
        {
            std::lock_guard<std::mutex> lock(queue_mutex);
            stop = true;
        }
        condition.notify_all(); // Despierta a todos para que mueran pacíficamente
        for(std::thread &worker: workers) {
            worker.join(); // Espera a que terminen su último trabajo (Graceful Shutdown)
        }
    }
};

template<LossFunction LossType>
void entrenar_modelo_con_evaluacion(MLP& modelo, DataLoader& loader, Adam& optimizador, int num_epochs, size_t batch_size) {
    
    for (int epoch = 1; epoch <= num_epochs; ++epoch) {
        loader.shuffleTrain();
        loader.resetTrain();
        float loss_epoca = 0.0f;

        while (true) {
            BatchView batch = loader.next_train_batch(batch_size);
            if (batch.samples == 0) break;

            optimizador.zero_grad();

            Tensor pred = modelo.forward(batch);
            float batch_loss = LossType::forward(pred, batch.Y_ptr, batch.num_outputs);
            Tensor dLoss = LossType::backward(pred, batch.Y_ptr, batch.num_outputs);
            
            loss_epoca += batch_loss;

            modelo.backward(dLoss);
            optimizador.step();
        }

        // Evaluación periódica en Test (para ver si realmente acierta las flores)
        if (epoch % 100 == 0) {
            loader.resetTest();
            size_t aciertos = 0;
            size_t total = 0;

            while (true) {
                BatchView test_batch = loader.next_test_batch(batch_size);
                if (test_batch.samples == 0) break;

                Tensor pred_test = modelo.forward(test_batch);

                for (size_t i = 0; i < pred_test.rows; ++i) {
                    // Argmax de la predicción de la IA
                    int idx_pred = 0;
                    float max_val = pred_test.at(i, 0);
                    for (size_t j = 1; j < pred_test.cols; ++j) {
                        if (pred_test.at(i, j) > max_val) {
                            max_val = pred_test.at(i, j);
                            idx_pred = static_cast<int>(j);
                        }
                    }

                    // Argmax del valor real (One-Hot)
                    int idx_real = 0;
                    float max_real = test_batch.Y_ptr[i * test_batch.num_outputs + 0];
                    for (size_t j = 1; j < test_batch.num_outputs; ++j) {
                        float val = test_batch.Y_ptr[i * test_batch.num_outputs + j];
                        if (val > max_real) {
                            max_real = val;
                            idx_real = static_cast<int>(j);
                        }
                    }

                    if (idx_pred == idx_real) aciertos++;
                    total++;
                }
            }

            float acc = (static_cast<float>(aciertos) / total) * 100.0f;
            std::printf("Epoch %4d | CrossEntropy Loss: %.4f | Test Accuracy: %zu/%zu (%.2f%%)\n", 
                        epoch, loss_epoca, aciertos, total, acc);
        }
    }
}

void handle_sigint(int) {

std::string leer_peticion_robusta(SOCKET client_socket) {
    std::string peticion_completa;
    char buffer[1024];
    int headers_end_pos = -1;
    size_t content_length = 0;

    while (true) {
        int bytes = recv(client_socket, buffer, sizeof(buffer), 0);
        if (bytes <= 0) break; // El cliente se desconectó o hubo error

        peticion_completa.append(buffer, bytes);

        // Fase A: Buscar el fin de las cabeceras HTTP
        if (headers_end_pos == -1) {
            size_t pos = peticion_completa.find("\r\n\r\n");
            if (pos != std::string::npos) {
                headers_end_pos = pos + 4; // Inicio del Body

                // Buscar si existe la cabecera Content-Length para saber cuánto Body esperar
                // NOTA: Esto es un mini-parser temporal solo para el tamaño.
                std::string upper_req = peticion_completa; 
                for(auto& c : upper_req) c = toupper(c); // Evitar problemas con "content-length" vs "Content-Length"
                
                size_t cl_pos = upper_req.find("CONTENT-LENGTH:");
                if (cl_pos != std::string::npos) {
                    size_t num_start = cl_pos + 15;
                    size_t num_end = upper_req.find("\r\n", num_start);
                    if (num_end != std::string::npos) {
                        content_length = std::stoull(peticion_completa.substr(num_start, num_end - num_start));
                    }
                }
            }
        }

        // Fase B: Si ya tenemos las cabeceras, verificar si tenemos el Body completo
        if (headers_end_pos != -1) {
            size_t body_recibido = peticion_completa.size() - headers_end_pos;
            if (body_recibido >= content_length) {
                break; // ¡Tenemos la petición HTTP al 100%! Salimos del bucle.
            }
        }
    }
    return peticion_completa;
}

// Función de ayuda para parsear parámetros de consulta (Query String)
std::unordered_map<std::string, std::string> parse_query_string(const std::string& query) {
    std::unordered_map<std::string, std::string> params;
    std::istringstream query_stream(query);
    std::string pair;
    while (std::getline(query_stream, pair, '&')) {
        size_t equal_pos = pair.find('=');
        if (equal_pos != std::string::npos) {
            params[pair.substr(0, equal_pos)] = pair.substr(equal_pos + 1);
        }
    }
    return params;
}

Adam::Adam(const std::vector<Tensor*>& params, float learning_rate) 
    : parametros(params), lr(learning_rate), beta1(0.9f), beta2(0.999f), epsilon(1e-8f), t(0) {
    if (learning_rate <= 0.0f) {
    throw std::invalid_argument("Learning rate must be positive");
    }

    // Inicializamos la memoria de momentos (m y v) con ceros exactos al tamaño de cada tensor
    m.reserve(parametros.size());
    v.reserve(parametros.size());
    for (Tensor* p : parametros) {
        if (p == nullptr) throw std::invalid_argument("Adam received a null Tensor");

        m.push_back(std::vector<float>(p->size(), 0.0f));
        v.push_back(std::vector<float>(p->size(), 0.0f));
    }
}

void Adam::zero_grad() {
    for (Tensor* p : parametros) {
        p->zero_grad();
    }
}

void Adam::step() {
    ++t;

    float beta1_t = std::pow(beta1, t);
    float beta2_t = std::pow(beta2, t);

    // Estos cálculos se hacen una vez por step, no por cada peso
    const float lr_t = lr * std::sqrt(1.0f - beta2_t)
                    / (1.0f - beta1_t);

    for (size_t i = 0; i < parametros.size(); ++i) {
        Tensor* p = parametros[i];
        
        // Acceso secuencial a memoria para favorecer la localidad de caché.
        for (size_t j = 0; j < p->size(); ++j) {
            const float grad = p->grad[j];
            
            m[i][j] = beta1 * m[i][j] + (1.0f - beta1) * grad;
            v[i][j] = beta2 * v[i][j] + (1.0f - beta2) * grad * grad;
            
            p->data[j] -= lr_t * m[i][j] / (std::sqrt(v[i][j]) + epsilon);
        }
    }
}

DataLoader::DataLoader(unsigned int seed) : gen(seed), total_samples(0), train_size(0) {}

void DataLoader::swap_samples(size_t i, size_t j) {
    if (i == j) return;
    for (size_t k = 0; k < num_inputs; ++k) {
        std::swap(X_data[i * num_inputs + k], X_data[j * num_inputs + k]);
    }
    for (size_t k = 0; k < num_outputs; ++k) {
        std::swap(Y_data[i * num_outputs + k], Y_data[j * num_outputs + k]);
    }
}

bool DataLoader::cargarCSV(const std::string& ruta, size_t inputs, size_t outputs) {
    std::ifstream archivo(ruta);
    if (!archivo) return false;

    num_inputs = inputs;
    num_outputs = outputs;
    X_data.clear(); Y_data.clear();
    X_data.reserve(10000 * num_inputs);
    Y_data.reserve(10000 * num_outputs);

    std::string linea;
    total_samples = 0;
    while (std::getline(archivo, linea)) {
        if (linea.empty()) continue;
        
        std::string_view sv(linea);
        size_t col = 0;
        bool valid = true;
        std::vector<float> temp_row;
        
        while (!sv.empty()) {
            size_t pos = sv.find(',');
            std::string_view token = (pos == std::string_view::npos) ? sv : sv.substr(0, pos);
            float val;
            auto [ptr, ec] = std::from_chars(token.data(), token.data() + token.size(), val);
            
            if (ec != std::errc()) { valid = false; break; }
            temp_row.push_back(val);
            
            if (pos == std::string_view::npos) break;
            sv = sv.substr(pos + 1);
        }
        
        if (valid && temp_row.size() == (num_inputs + num_outputs)) {
            for(size_t i=0; i<num_inputs; ++i) X_data.push_back(temp_row[i]);
            for(size_t i=0; i<num_outputs; ++i) Y_data.push_back(temp_row[num_inputs + i]);
            total_samples++;
        }
    }
    return true;
}

void DataLoader::split_train_test(float train_ratio) {
    train_size = static_cast<size_t>(total_samples * train_ratio);
    
    // Mezcla inicial de todo el dataset
    std::vector<size_t> indices(total_samples);
    std::iota(indices.begin(), indices.end(), 0);
    std::shuffle(indices.begin(), indices.end(), gen);
    
    std::vector<float> new_X(X_data.size());
    std::vector<float> new_Y(Y_data.size());
    
    for(size_t i=0; i<total_samples; ++i) {
        size_t old_idx = indices[i];
        for(size_t k=0; k<num_inputs; ++k) new_X[i * num_inputs + k] = X_data[old_idx * num_inputs + k];
        for(size_t k=0; k<num_outputs; ++k) new_Y[i * num_outputs + k] = Y_data[old_idx * num_outputs + k];
    }
    X_data = std::move(new_X);
    Y_data = std::move(new_Y);
    
    train_index = 0;
    test_index = train_size;
}

void DataLoader::shuffleTrain() {
    if (train_size <= 1) return;
    for (size_t i = train_size - 1; i > 0; --i) {
        std::uniform_int_distribution<size_t> dist(0, i);
        swap_samples(i, dist(gen));
    }
    train_index = 0;
}

void DataLoader::resetTrain() { train_index = 0; }
void DataLoader::resetTest() { test_index = train_size; }

BatchView DataLoader::next_train_batch(size_t batch_size) {
    if (batch_size == 0 || train_index >= train_size) return {nullptr, nullptr, 0, 0, 0};
    
    size_t current_batch_size = std::min(batch_size, train_size - train_index);
    BatchView view;
    view.X_ptr = &X_data[train_index * num_inputs];
    view.Y_ptr = &Y_data[train_index * num_outputs];
    view.samples = current_batch_size;
    view.num_inputs = num_inputs;
    view.num_outputs = num_outputs;
    
    train_index += current_batch_size;
    return view;
}

BatchView DataLoader::next_test_batch(size_t batch_size) {
    if (batch_size == 0 || test_index >= total_samples) return {nullptr, nullptr, 0, 0, 0};
    
    size_t current_batch_size = std::min(batch_size, total_samples - test_index);
    BatchView view;
    view.X_ptr = &X_data[test_index * num_inputs];
    view.Y_ptr = &Y_data[test_index * num_outputs];
    view.samples = current_batch_size;
    view.num_inputs = num_inputs;
    view.num_outputs = num_outputs;
    
    test_index += current_batch_size;
    return view;
}

Layer::Layer(size_t nin, size_t nout, std::mt19937& gen, bool is_linear) 
    : W(nin, nout), b(1, nout), is_linear(is_linear) {
    
    // Inicialización de pesos (He Initialization para ReLU)
    float scale = std::sqrt(2.0f / nin);
    std::normal_distribution<float> d(0.0f, scale);
    
    for (size_t i = 0; i < W.size(); ++i) {
        W.data[i] = d(gen);
    }
    for (size_t i = 0; i < b.size(); ++i) {
        b.data[i] = 0.0f; // Sesgos a 0
    }
}

Tensor Layer::forward(const Tensor& X) {
    X_cache = X; // Guardamos la entrada para el backward
    Tensor out(X.rows, W.cols);

    // Multiplicación de Matrices: Out = X * W + b
    #pragma omp parallel for
    for (int i = 0; i < (int)X.rows; ++i) {
        for (int j = 0; j < (int)W.cols; ++j) {
            float sum = 0.0f;
            for (int k = 0; k < (int)W.rows; ++k) {
                sum += X.at(i, k) * W.at(k, j);
            }
            
            float val = sum + b.at(0, j);
            
            // Función de Activación ReLU
            if (!is_linear && val < 0.0f) {
                val = 0.0f;
            }
            out.at(i, j) = val;
        }
    }
    
    out_cache = out; // Guardamos la salida para la derivada de ReLU
    return out;
}

Tensor Layer::backward(const Tensor& dOut) {
    Tensor dZ(dOut.rows, dOut.cols);

    // 1. Derivada de la activación (ReLU)
    #pragma omp parallel for
    for (int i = 0; i < (int)dOut.rows; ++i) {
        for (int j = 0; j < (int)dOut.cols; ++j) {
            if (!is_linear && out_cache.at(i, j) <= 0.0f) {
                dZ.at(i, j) = 0.0f;
            } else {
                dZ.at(i, j) = dOut.at(i, j);
            }
        }
    }

    // 2. Gradientes de los Pesos: dW = X^T * dZ
    #pragma omp parallel for
    for (int i = 0; i < (int)W.rows; ++i) {
        for (int j = 0; j < (int)W.cols; ++j) {
            float sum = 0.0f;
            for (int k = 0; k < (int)X_cache.rows; ++k) {
                sum += X_cache.at(k, i) * dZ.at(k, j);
            }
            // Acumulamos el gradiente (Adam lo usará luego)
            #pragma omp atomic
            W.grad[i * W.cols + j] += sum;
        }
    }

    // 3. Gradientes de los Sesgos: db = suma(dZ)
    for (int j = 0; j < (int)b.cols; ++j) {
        float sum = 0.0f;
        for (int i = 0; i < (int)dZ.rows; ++i) {
            sum += dZ.at(i, j);
        }
        b.grad[j] += sum;
    }

    // 4. Gradiente para pasar a la capa anterior: dX = dZ * W^T
    Tensor dX(X_cache.rows, X_cache.cols);
    #pragma omp parallel for
    for (int i = 0; i < (int)dX.rows; ++i) {
        for (int j = 0; j < (int)dX.cols; ++j) {
            float sum = 0.0f;
            for (int k = 0; k < (int)W.cols; ++k) {
                sum += dZ.at(i, k) * W.at(j, k);
            }
            dX.at(i, j) = sum;
        }
    }

    return dX;
}
Tensor Layer::forward_inference(const Tensor& X) const {
    // NO HAY X_cache = X; (No guardamos estado, es solo lectura)
    Tensor out(X.rows, W.cols);

    #pragma omp parallel for
    for (int i = 0; i < (int)X.rows; ++i) {
        for (int j = 0; j < (int)W.cols; ++j) {
            float sum = 0.0f;
            for (int k = 0; k < (int)W.rows; ++k) {
                sum += X.at(i, k) * W.at(k, j);
            }
            float val = sum + b.at(0, j);
            if (!is_linear && val < 0.0f) val = 0.0f; // ReLU
            out.at(i, j) = val;
        }
    }
    // NO HAY out_cache = out;
    return out;
}

MLP::MLP(const std::vector<size_t>& sizes, std::mt19937& gen) {
    layers.reserve(sizes.size() - 1);
    for (size_t i = 0; i < sizes.size() - 1; ++i) {
        bool is_last_layer = (i == sizes.size() - 2);
        layers.emplace_back(sizes[i], sizes[i+1], gen, is_last_layer); 
    }
}

std::vector<Tensor*> MLP::parameters() {
    std::vector<Tensor*> params;
    for (auto& layer : layers) {
        params.push_back(&layer.W);
        params.push_back(&layer.b);
    }
    return params;
}

Tensor MLP::forward(const BatchView& batch) {
    // 1. Transformar el BatchView (datos crudos) a nuestro primer Tensor X
    Tensor X(batch.samples, batch.num_inputs);
    for (size_t i = 0; i < batch.samples; ++i) {
        for (size_t j = 0; j < batch.num_inputs; ++j) {
            X.at(i, j) = batch.X_ptr[i * batch.num_inputs + j];
        }
    }

    // 2. Propagar X por todas las capas
    Tensor out = X;
    for (size_t i = 0; i < layers.size(); ++i) {
        out = layers[i].forward(out);
    }
    
    return out; // Predicción final [batch_size, salidas]
}

void MLP::backward(const Tensor& dLoss) {
    Tensor dOut = dLoss;
    
    // Recorrer las capas al revés aplicando la regla de la cadena
    for (int i = (int)layers.size() - 1; i >= 0; --i) {
        dOut = layers[i].backward(dOut);
    }
}


void MLP::save(const std::string& filename) {
    std::ofstream out(filename, std::ios::binary);
    if (!out) throw std::runtime_error("No se pudo crear archivo.");

    out.write(MLP_MAGIC.c_str(), 4);
    writeBinary(out, MLP_VERSION);

    auto params = parameters();
    
    size_t num_tensors = params.size();
    writeBinary(out, num_tensors);

    for (Tensor* t : params) {
        writeBinary(out, t->rows); 
        writeBinary(out, t->cols); 
        writeBinary(out, t->data); 
    }
    std::cout << "Modelo guardado con exito en " << filename << "\n";
}

void MLP::load(const std::string& filename) {
    std::ifstream in(filename, std::ios::binary);
    if (!in) throw std::runtime_error("No se encontró el archivo del modelo.");

    // 1. Validar Magic Number
    char magic[5] = {0};
    in.read(magic, 4);
    if (std::string(magic) != MLP_MAGIC) {
        throw std::runtime_error("Formato de archivo inválido. No es un modelo de IA.");
    }

    // 2. Validar Versión
    uint32_t version;
    readBinary(in, version);
    if (version != MLP_VERSION) {
        throw std::runtime_error("Versión del modelo incompatible.");
    }

    // 3. Validar Topología (número de tensores)
    size_t num_tensors;
    readBinary(in, num_tensors);
    auto params = parameters();
    
    if (num_tensors != params.size()) {
        throw std::runtime_error("La topología de la red no coincide con la del archivo.");
    }

    // 4. Cargar los datos validando las dimensiones de cada tensor
    for (Tensor* t : params) {
        size_t rows, cols;
        readBinary(in, rows);
        readBinary(in, cols);
        
        if (rows != t->rows || cols != t->cols) {
            throw std::runtime_error("Dimensiones incompatibles en las capas de la red.");
        }
        
        readBinary(in, t->data); // Magia: Carga toda la memoria a la RAM
    }
    std::cout << "Modelo cargado con exito desde " << filename << "\n";
}

Tensor MLP::inference(const BatchView& batch) const {
    Tensor current(batch.samples, batch.num_inputs);
    for (size_t i = 0; i < batch.samples; ++i) {
        for (size_t j = 0; j < batch.num_inputs; ++j) {
            current.at(i, j) = batch.X_ptr[i * batch.num_inputs + j];
        }
    }
    for (const auto& layer : layers) {
        current = layer.forward_inference(current);
    }
    return current;
}
